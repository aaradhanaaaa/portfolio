# 🌐 Aradhana Rani – Portfolio

A modern, responsive, and interactive portfolio website showcasing my journey as an **ECE student**, **Frontend Developer**, and **AI Enthusiast**.

---

## 📌 About The Portfolio

This portfolio reflects my passion for **technology, frontend development, and modern UI design**. It is built with a futuristic dark-themed interface featuring smooth layouts, interactive sections, and responsive design.

The website includes:

* 👩‍💻 Personal introduction and profile section
* 🚀 Technical skills and technology stack
* 📂 Featured projects with live previews
* 📜 Certifications and achievements
* 📄 Resume access and social links
* 🌗 Dark/Light mode support
* 📱 Fully responsive design for all devices

---
